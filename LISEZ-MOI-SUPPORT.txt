- support.html contient les liens WhatsApp, Discord, YouTube et TikTok.

- Cette archive prépare les fichiers du site ; elle ne publie pas automatiquement la mise à jour sur GitHub Pages.

MISE A JOUR V4 - BOUTIQUE ET CODES D'ACHAT
- Depuis boutique.html, choisir un jeu ouvre payement.html?jeu=... .
- payement.html adapte le nom, l'image et le format attendu au jeu sélectionné.
- Le bouton « Contacter un agent pour obtenir un code d’achat » ouvre WhatsApp au +241 02 47 11 71 avec un message prérempli.

- Garder payement.html au même niveau que les autres pages HTML et les images PNG.


MISE A JOUR V5 - LANCEUR ANDROID / GITHUB
- Les boutons Jouer de Blox Fruit, Space Battle et Speed Race passent par game-launcher.js sur Android.
- Le lanceur tente d'abord les URI gamezone://bloxfruit, gamezone://spacebattle et gamezone://speedrace. L'application native doit enregistrer le schéma correspondant pour être ouverte.
- Si aucune application ne prend en charge l'URI, le site recherche un APK correspondant dans les assets des Releases publics du dépôt GitHub darkaigrisff/Game-zone.
- Pour déclencher un téléchargement Android, il faut publier les APK dans GitHub Releases avec ces noms : Blox-Fruit.apk, Space-Battle.apk, Speed-Race.apk et/ou Football-Ligue-2027.apk. Le code accepte aussi quelques variantes de nom.
- Si aucun APK correspondant n'est publié, le lanceur ouvre la version jouable dans le navigateur (Football Ligue 2027 ouvre Actualités tant qu'aucun jeu n'est disponible).
- Limitation Android : une page web ne peut pas lire directement la liste des applications installées. Elle peut seulement tenter d'ouvrir un lien profond reconnu par l'application, puis utiliser une solution de secours. Le téléchargement d'un APK ne l'installe pas silencieusement : Android affiche ses propres confirmations.
- L'archive ne publie pas les fichiers sur GitHub Pages et ne crée pas les APK. Il faut téléverser cette archive dans le dépôt du site et publier les APK dans Releases pour que la recherche trouve des fichiers.


MISE A JOUR V7 :
- jeux.html : guides des jeux Blox Fruit, Space Battle et FOOTBALL LIGUE 2027.
- capture1.jpg : capture attendue pour Blox Fruit ; capture2.jpg : capture attendue pour Space Battle. Place ces deux fichiers à la racine à côté de index.html. Si elles manquent, les images d’illustration servent de secours.

MISE À JOUR V8 — COMPTE GAME ZONE (PROTOTYPE)
- Nouvelle page compte.html : inscription, connexion, profil et accès aux deux jeux.
- account.js permet à Blox Fruit et Space Battle de lire le pseudo connecté dans le même navigateur.
- Limite importante : cette version stocke les comptes localement dans le navigateur. Ce n'est PAS une authentification sécurisée ni une synchronisation entre téléphones.
- Aucun paiement réel ne crédite encore les T-Bucks. Pour le lancement, il faudra une API/serveur avec base de données et confirmation des paiements côté serveur. Ne pas présenter ce prototype comme un système de paiement fonctionnel.


MISE A JOUR V9 - INSCRIPTION, CONNEXION ET MENU PROFIL
- signup.html : création de compte, puis redirection vers home.html.
- login.html : connexion, puis redirection vers home.html.
- home.html et index.html : le pseudo apparaît dans le bouton de profil en haut. Le menu présente Blox Fruit (bloxfruit.png), Space Battle (space.png), l'état de liaison et la déconnexion.
- Si un compte est connecté puis ouvre game.html ou space.html, le jeu affiche « Bienvenue [pseudo] ! » et le menu mémorise la liaison sur cet appareil.
- Important : ce prototype garde les comptes dans le stockage du navigateur. Il ne synchronise pas encore plusieurs téléphones et n'est pas une authentification sécurisée.
- Limite Android : une page web ne peut pas lire directement la liste des applications installées. Pour reconnaître réellement une application native, il faut créer les APK et configurer un lien profond/package reconnu par Android. Les jeux actuels restent accessibles en version navigateur.


MISE À JOUR V11 — DÉTAILS DES JEUX ET TÉLÉCHARGEMENTS
- detail.html est une page de détails réutilisable : detail.html?jeu=bloxfruit, detail.html?jeu=space et detail.html?jeu=speed.
- La page d’accueil (index.html et home.html) affiche un bouton « Détails » pour chaque jeu disponible, tout en gardant « Jouer ».
- Les images locales bloxfruit.png et space.png sont utilisées pour leurs jeux ; Speed Race dispose d’une illustration CSS pour ne pas dépendre d’un fichier image manquant.
- Le bouton de téléchargement ouvre download.html, qui recherche un véritable fichier APK dans les GitHub Releases publiques de darkaigrisff/Game-zone. Si aucun APK n’est publié, la page l’indique et propose la version navigateur ; elle ne prétend pas télécharger un fichier inexistant.
- Pour rendre le téléchargement APK actif, publier chaque APK dans GitHub Releases avec un nom reconnaissable : BloxFruit.apk ou Blox-Fruit.apk ; SpaceBattle.apk ou Space-Battle.apk ; SpeedRace.apk ou Speed-Race.apk.
- La mise à jour est un dossier de site : elle ne publie pas automatiquement les changements sur GitHub Pages et ne fabrique pas d’APK. Téléverser les fichiers du dossier dans le dépôt du site.
